# OCPP 2.1 JSON schemas

The `*.json` files in this directory are the official OCPP 2.1 Edition 1 JSON schemas
(part 3, 2025-01-23), copied verbatim and unmodified from the OCPP 2.1 specification package of the Open Charge Alliance.

Copyright © 2010 – 2025 Open Charge Alliance. They are made available under the
[Creative Commons Attribution-NoDerivatives 4.0 International Public License](https://creativecommons.org/licenses/by-nd/4.0/legalcode).
See https://openchargealliance.org for the full specification.

They are the input of `v21/codegen/generate_v21.py`, which generates the Kotlin message model of the `v21` module and
the schema-validated test samples in `v21/src/test/resources/samples`.
